3대 무결성 프로토콜 (Protocols)

1. Image Fail-Safe

Yes24, 교보문고 등의 CORS 보안 차단을 우회하기 위해 wsrv.nl 이미지 프록시를 통과합니다. 만약 검색에 실패하더라도 onerror 속성을 통해 고급스러운 더미(Placeholder) 이미지로 즉각 대체되어 엑스박스를 완벽히 방지합니다.

2. Dynamic Theming

AI가 추출한 책 표지의 지배적인 색상(Main)과 포인트 색상(Accent)을 CSS 변수(:root)로 자동 치환합니다. 어떤 책을 입력하든 표지와 인포그래픽이 시각적인 물아일체를 이룹니다.

3. Embedded Widget

단순 텍스트 출력을 넘어, Yes24의 실제 상품 페이지로 직결되는 UI 위젯 및 버튼을 HTML 내부에 직접 디자인하여 렌더링합니다. 독서 기록이 하나의 랜딩 페이지로 기능합니다.

6단계 분석 프레임워크 (Framework)

  • 01

    Hero Section : 표지와 텍스트 해부

    프레임 없이 깔끔하게 배치된 책 표지 이미지와 함께, 저자/출판사 정보, 책을 관통하는 3가지 핵심 키워드 뱃지를 최상단에 시각화합니다.

  • 02

    Synopsis & Intention : 내용과 의도

    책의 전반적인 줄거리(핵심 논지)를 요약하고, 작가가 이 책을 집필하게 된 시대적/개인적 배경과 궁극적인 메시지를 통찰력 있게 도출합니다.

  • 03

    The Core Quote : 발췌와 변주

    테마 컬러가 적용된 따옴표 디자인 안에 AI가 직접 선정한 텍스트의 핵심 명문장을 배치하고, 그 문장이 지니는 철학적 의미를 해설합니다.

  • 04

    Critic's Report : 비평적 시선

    단순한 요약을 넘어, 작가의 한계점이나 텍스트의 독창성, 시대적 맥락에서의 가치를 분석한 전문가 수준의 에디토리얼 평론을 작성합니다.

  • 05

    Paradigm Shift : 인식의 확장

    이 책을 읽기 전의 보편적 인식(Before)과 읽은 후 획득한 새로운 시야(After)를 대비시켜, 독서의 실질적인 효용을 시각적으로 증명합니다.

  • 06

    Curator's Note : 큐레이션

    리포트를 마무리하는 20자 이내의 날카로운 한 줄 평과 검색용 해시태그, 그리고 사유를 확장해 줄 연관 도서 1권을 논리적으로 추천합니다.
